# 04 - 开发步骤规范

> 本文档定义 10 个开发阶段的详细步骤、每阶段的验收标准。
> 严格按顺序推进，一个阶段验收通过再进入下一个，不跳步、不跨阶段。

---

| 阶段 | 名称 | 预估用时 | 优先级 | 验收通过标准 |

## 🔵 阶段 1：项目初始化 + 基础框架搭建

### 目标
搭好能跑起来的空壳窗口，验证 PySide6 环境、主题加载、基础布局。

### 详细步骤
1. **创建虚拟环境**（Python 3.10+），安装 requirements.txt
2. 创建 `src/` 代码目录，按 [技术选型文档](02_技术选型文档.md) 的目录结构建空文件和 `__init__.py`
3. 创建 `config.example.json`（模板，不含真实 KEY）
4. 写 `src/main.py`：启动 QApplication，加载主窗口
5. 写 `src/ui/main_window.py`：
   - 窗口标题「自动早晚安小助手」，尺寸 1080x760
   - 加载淡蓝色 QSS 主题文件
   - 按 UI 规范搭好四个空区域：标题栏、顶栏按钮区、中间滚动区、底栏
   - 顶栏放四个空按钮（一键生成全部、生成天气、生成推荐、生成分享）
   - 中间滚动区放三个空模块面板（标题 + 空卡片网格）
   - 底栏放状态区 + 两个打包按钮
6. 写 `src/ui/styles/theme_light_blue.qss`：按 [UI 规范](03_UI设计规范.md) 色值写基础 QSS
7. 写 `src/utils/logger.py`：初始化 logging，日志存 `logs/YYYY-MM-DD.log`
8. 测试运行：`python src/main.py`

### 验收标准 ✅
- [ ] 双击 main.py 能弹出窗口，无报错闪退
- [ ] 窗口背景是淡蓝色 `#EBF4FB`
- [ ] 四个区域布局完整，按钮文字正确
- [ ] 窗口可缩放、可关闭，不卡死
- [ ] logs 文件夹自动生成，当天日志文件有内容

## 🔵 阶段 2：配置管理模块

### 目标
实现配置文件读写、设置页弹窗，验证配置持久化。

### 详细步骤
1. 写 `src/config.py`：
   - `load_config()`：读 config.json，不存在就从 example 复制
   - `save_config()`：写 config.json，加异常处理
2. 写 `src/ui/settings_dialog.py`（设置弹窗）：
   - Agnes AI：API KEY 输入框、画图模型下拉框
   - 和风天气：API KEY 输入框、城市下拉框
   - 存储设置：路径输入框 + 浏览按钮、图片质量滑块
   - 标签设置：必须标签输入框（逗号分隔）
   - 底部「保存」「取消」按钮
   - 保存时校验必填项（两个 KEY 不能为空），校验不通过弹警告
3. 主窗口顶栏加「⚙️ 设置」按钮，点击打开设置弹窗
4. 预填用户给的两个 API KEY（写入默认 example，首次启动自动带到配置）
5. 测试：改设置 → 保存 → 关软件 → 重开 → 确认设置没变

### 验收标准 ✅
- [ ] 点设置按钮能打开弹窗，各字段有默认值
- [ ] 修改任意字段保存后，config.json 内容变了
- [ ] 关软件重开，设置仍然保留
- [ ] API KEY 留空时点保存弹警告，不让存
- [ ] 路径浏览按钮能打开文件夹选择对话框

## 🔵 阶段 3：天气模块（最核心，先搞定）

### 目标
实现和风天气查询 + Agnes AI 生成早晚安文案 + 配图 + 水印。

### 详细步骤
1. **写 API 层** `src/api/weather.py`：
   - 封装和风天气「实时天气」接口（城市：焦作）
   - 返回结构化字典：温度、天气状况、风向风力、湿度、更新时间
   - 加超时、异常处理、返回错误信息
2. **写 API 层** `src/api/agnes_ai.py`：
   - `generate_text(prompt)`：文案生成接口，返回字符串数组
   - `generate_image(prompt, size)`：图片生成接口，返回图片 bytes 或 base64
   - 注意 size 参数：竖图用 `1024x1536`（9:16？不对，1024x1536=2:3，正方形 1024x1024，按 Agnes 文档实际支持的来——**先查 Agnes API 文档确认尺寸参数，详见 [05_API接口文档](05_API接口文档.md)**）
3. **写核心层** `src/core/content_generator.py`：
   - `generate_morning_content(weather_data)`：早安 Prompt → 生成 3 条文案 + 3 张图
   - `generate_night_content(weather_data)`：晚安 Prompt → 生成 3 条文案 + 3 张图
   - Prompt 必须按需求文档写：10-20字、阳光正能量、融入天气信息、第一人称小青、必须标签
4. **写水印层** `src/core/image_watermark.py`：
   - `add_watermark(image_bytes, text)`：按 UI 规范加右下角半透明白字水印
5. **写卡片组件** `src/ui/widgets/content_card.py`：
   - 图片预览区 + 文案区 + 标签区 + 三个按钮（复制/保存/换一条）
   - 图片点击弹放大预览
6. **写模块面板** `src/ui/widgets/module_panel.py`：
   - 标题 + 「全部重来」按钮 + 卡片网格（QScrollArea 横向滚动或 FlowLayout 换行）
7. 接入主窗口：点「生成天气」按钮 → 走 QThread 子线程生成 → 信号回传 → 渲染卡片
8. 加加载状态：生成中按钮置灰 + 进度提示

### 验收标准 ✅
- [ ] 点生成天气后，30-60 秒内出结果
- [ ] 早安卡片 3 张，每张有不同文案 + 不同配图
- [ ] 晚安卡片 3 张，同上
- [ ] 文案长度 10-20 字，包含 `#早安理工#` / `#晚安理工#` / `#每日话题#`
- [ ] 图片右下角有水印「早安理工 · 今天日期」/「晚安理工 · 今天日期」，不挡主体
- [ ] 断网时弹友好提示，不崩溃
- [ ] 生成中按钮是灰的，底栏有进度提示

## 🟢 阶段 4：小青超推荐模块

### 目标
实现书籍 / 电影 / 纪录片三种推荐的生成。

### 详细步骤
1. 在 `src/core/content_generator.py` 加三个函数：
   - `generate_book_recommend(count=3)`：生成 3 本书的推荐，含书名、作者、推荐理由（150-250字）、标签
   - `generate_movie_recommend(count=3)`：同上，电影推荐
   - `generate_docu_recommend(count=3)`：同上，纪录片推荐
   - 每个都调 Agnes AI 写文案 + 画配图（写实海报风）
2. Prompt 要求：阳光正能量、第一人称小青、150-250字、必须标签 `#小青超推荐#` + `#每日话题#`
3. 配图水印文字「小青超推荐」+ 日期
4. 主窗口点「生成推荐」按钮 → 分别生成三种 → 合并显示（推荐模块下分三个子区域：书籍 / 电影 / 纪录片，每个子区域放卡片）
5. 复用阶段 3 的卡片组件和模块面板
6. 最终从三种里各挑 1-2 条候选（按需求文档）

### 验收标准 ✅
- [ ] 点生成推荐后，能同时拿到书籍 3 条 + 电影 3 条 + 纪录片 3 条
- [ ] 文案 150-250 字，第一人称「小青」，标签有 `#小青超推荐#` `#每日话题#`
- [ ] 配图是写实海报风，右下角有水印
- [ ] 三个子区域布局清晰，不混乱
- [ ] 单独生成推荐（不点一键全部）功能正常

## 🔵 阶段 6：核心交互（换一条 / 全部重来 / 复制 / 保存）

### 目标
让所有按钮真的能用，操作有反馈。

### 详细步骤
1. **📋 复制文案按钮**：
   - 拼接「正文 + 空格 + 所有标签」到剪贴板（QClipboard）
   - 弹成功提示「文案已复制，快去发 QQ 动态吧！」
   - 同时把这条标记为「已精选」

2. **💾 保存图片按钮**：
   - 按文件存储规范，把图片存到 `小青素材/当天日期/模块名/配图N.jpg`
   - 同时把对应文案存成 `文案N.txt`
   - 更新当天的 `全部备份.json`，标记此条为 `selected: true`（已精选）
   - 弹成功提示「图片已保存到：路径」

3. **🔄 换一条按钮（单条）**：
   - 读取这条的类型（早安/书籍/科普...），单独调用 content_generator 重新生成 1 条
   - 只替换这张卡片的文案和图片，其他卡片不动
   - 卡片显示半透明加载动画

4. **🔄 全部重来按钮（模块级）**：
   - 清空该模块所有卡片
   - 重新调生成函数，生成全新一批
   - 整个模块面板显示加载蒙层

5. **🎯 一键生成全部**：
   - 依次调用：天气 → 推荐 → 分享（串行，避免 API 并发压力）
   - 每完成一个模块就渲染出来
   - 底栏进度显示「1/3 天气已完成...」

6. 异常处理：所有按钮操作失败都要弹提示，不能静默失败

### 验收标准 ✅
- [ ] 复制文案后，去记事本粘贴能看到完整文案 + 标签
- [ ] 保存图片后，去对应文件夹能看到 JPG + TXT，文件名正确
- [ ] 点某条「换一条」，只有这条变了，其他卡片内容不变
- [ ] 点模块「全部重来」，整个模块卡片全换
- [ ] 一键生成全部能按顺序生成三个模块，有进度提示
- [ ] 全部备份.json 里有当天内容，已精选的有标记

## 🟢 阶段 7：文件管理 + 历史查看

### 目标
自动备份到日期文件夹，软件内能看历史内容。

### 详细步骤
1. **写文件管理模块** `src/core/file_manager.py`：
   - `ensure_date_folder()`：确保当天日期文件夹存在，不存在就创建
   - `save_content_item()`：存单条（图+文案），返回保存路径
   - `update_backup_json()`：更新当天的 `全部备份.json`
   - `list_history_dates()`：列出小青素材下所有日期文件夹
   - `load_history(date)`：加载某天的 `全部备份.json`，返回结构化数据
2. **主窗口加「📜 历史」按钮**，点击打开 `history_dialog.py`
3. **写历史弹窗** `src/ui/history_dialog.py`：
   - 左侧日期列表（YYYY-MM-DD），点击选日期
   - 右侧显示当天所有内容（按模块分组的卡片，只读展示）
   - 支持「复制文案」「另存图片」按钮（对历史内容也能用）
4. 每次生成完成后，自动调用 file_manager 备份（不管用户点没点保存）
5. 首次启动，自动创建「小青素材」文件夹

### 验收标准 ✅
- [ ] 生成内容后，日期文件夹自动创建，里面有图+文案+备份 JSON
- [ ] 点历史按钮能打开弹窗，左侧有日期列表
- [ ] 点日期能看到那天生成的所有内容
- [ ] 历史内容能复制文案、另存图片
- [ ] 软件关了重开，历史仍然在
- [ ] 修改设置里的存储路径后，新内容存到新路径，旧内容不迁移（提示用户）

## 🟢 阶段 8：打包功能（两个 zip 按钮）

### 目标
实现精选内容打包、全部草稿打包。

### 详细步骤
1. 在 `file_manager.py` 加：
   - `pack_selected(date)`：读取当天备份 JSON，挑 `selected: true` 的内容 → 复制到临时目录 → 打成 zip → 存到当天日期文件夹 → 返回 zip 路径
   - `pack_all(date)`：把当天所有内容（全部备份.json + 所有子文件夹）打成 zip
2. 用 Python 标准库 `zipfile`（不引入额外依赖）
3. 底栏两个按钮：
   - 📦 打包精选内容 → 调 pack_selected → 弹窗「打包完成！路径：XXX」+「打开文件夹」按钮
   - 🗂️ 打包全部草稿 → 调 pack_all → 同上提示
4. 打包过程走子线程，大文件不卡 UI
5. 加异常处理：当天没内容弹警告「今天还没生成内容哦」

### 验收标准 ✅
- [ ] 生成并挑几条保存后，点打包精选，zip 里只有挑过的那些图+文案
- [ ] 点打包全部草稿，zip 里有全部生成过的内容（含废稿）+ 备份 JSON
- [ ] zip 解压后文件结构清晰，不乱
- [ ] 没生成内容时点打包弹警告，不报错
- [ ] 打包过程 UI 不卡死，底栏有进度提示

## 🟢 阶段 9：UI 美化 + 水印优化

### 目标
整体视觉精修，确保淡蓝色主题统一、水印干净清爽。

### 详细步骤
1. **QSS 精修**：
   - 补全所有组件样式（下拉框、滑块、滚动条、输入框、弹窗）
   - 滚动条做成细淡蓝色（不要系统原生粗灰条）
   - 卡片加悬停效果：稍微上浮 + 轻微阴影
   - 按钮加过渡动画（Qt 不支持 CSS transition，用伪状态切换模拟）
2. **图标替换**：
   - 所有按钮前加 SVG 小图标（🎯🌤️📚💡⚙️📜📋💾🔄📦🗂️）
   - 用 Qt 资源系统（.qrc）打包图标，避免文件散落
3. **水印优化**：
   - 根据图片实际尺寸动态计算字号（UI 规范已定义）
   - 加黑色半透明描边，亮图也能看清
   - 检测图片底部亮度，如果太浅就自动降低水印透明度 / 加深色阴影
4. **空状态提示**：
   - 没生成内容时，三个模块面板显示「点上方「生成 XX」按钮开始创作吧！」占位插画（SVG 淡蓝线稿）
5. **响应式布局**：
   - 窗口放大缩小时，卡片网格自动调整列数
   - 最小尺寸 960x640，再小弹提示「窗口太小啦，请拉大一点」

### 验收标准 ✅
- [ ] 所有组件都是淡蓝色风格，没有系统原生灰组件
- [ ] 滚动条是细淡蓝色
- [ ] 卡片悬停有视觉反馈
- [ ] 图片底部亮/暗时，水印都能看清，不糊
- [ ] 拉宽窗口，卡片自动从 3 列变 4 列、5 列
- [ ] 空状态有友好占位提示

   - [ ] 换一条：单条替换正常
   - [ ] 全部重来：模块全换正常
   - [ ] 复制文案：粘贴内容正确
   - [ ] 保存图片：文件正确，水印有
   - [ ] 历史查看：日期列表正确，内容能看，复制/另存正常
   - [ ] 打包精选：zip 内容正确
   - [ ] 打包全部：zip 内容正确
   - [ ] 断网测试：弹友好提示，不崩溃
   - [ ] 无效 KEY 测试：提示去设置改 KEY
   - [ ] 连续用 1 小时：内存不泄漏，不卡死

2. **Bug 修复**：所有自测发现的问题修复后，回归测试再测一遍

3. **PyInstaller 打包**：
   - 按技术选型文档的命令打包
   - 把 `小青素材` 文件夹先删掉（不要带测试数据）

# 01 - 项目需求文档

> 本文档是与用户确认后的最终需求，所有开发以此为准。
> 变更需求必须先与用户确认，再更新本文档。

---

## 一、基本信息

| 项目 | 内容 |
|------|------|
| 软件名称 | 自动早晚安小助手 |
| 运行平台 | Windows 10 / 11 |
| 交付方式 | 绿色免安装版（解压即用，双击 exe 打开） |
| UI 风格 | 简洁直观，淡蓝色主色调 |
| 用户人设 | "小青"——河南理工大学校园号运营者 |

---

## 二、三大核心内容模块

### 🔹 模块1：天气（早晚安理工）——每日必须有

| 项目 | 规范 |
|------|------|
| 数据源 | 和风天气 API，查询「焦作」天气（location=101181101 或 city=焦作） |
| 产出数量 | 早安理工 1 组 + 晚安理工 1 组；每组含 2-3 条候选文案 + 2-3 张候选配图 |
| 文案长度 | 10-20 字，超短问候语 |
| 文案风格 | 一句话 + emoji，阳光正能量；天气信息（温度/晴雨/风）自然融入句子，AI 灵活处理 |
| 文案口吻 | 第一人称"小青"，称呼同学为"小栗子们"或"理工学子们" |
| 参考文案 | 「今天晴 26℃，微风正好，早安理工 ☀️」「月亮照进窗子，祝小栗子们今晚好梦 🌙」 |
| 必须标签 | `#早安理工#` + `#每日话题#`（早安）；`#晚安理工#` + `#每日话题#`（晚安） |
| 配图类型 | 写实摄影风，结合当天气氛（晴天蓝天、雨天校园、晚霞等） |
| 配图比例 | 竖屏（9:16 或 3:4）或正方形（1:1），AI 灵活选择 |
| 配图水印 | 角落印「早安理工 · YYYY-MM-DD」/「晚安理工 · YYYY-MM-DD」，白色半透明，不遮挡画面主体 |

---

### 🔹 模块2：小青超推荐（书籍 / 电影 / 纪录片）

| 项目 | 规范 |
|------|------|
| 产出内容 | 每天三种类型都给（书 + 电影 + 纪录片），最终从每种里挑 1-2 个作为主推候选 |
| 每组数量 | 每种类型出 2-3 条候选推荐（含文案 + 配图） |
| 文案长度 | 150-250 字 |
| 文案风格 | 阳光正能量、真诚推荐，不生硬；要有推荐理由 + 亮点 + 一句话总结 |
| 文案口吻 | 第一人称"小青"，如「小青今天给大家挖到一部宝藏电影……」 |
| 必须标签 | `#小青超推荐#` + `#每日话题#`，可加 `#好书推荐#` / `#电影推荐#` / `#纪录片推荐#` 等 |
| 配图类型 | 写实风格：书籍→书本封面+校园场景；电影→电影海报风格；纪录片→自然/人文摄影感 |
| 配图比例 | 竖屏或正方形，灵活 |
| 配图水印 | 角落印「小青超推荐」+ 日期，白色半透明 |

---

### 🔹 模块3：小青爱分享（科普冷知识 / 生活小知识等）

| 项目 | 规范 |
|------|------|
| 内容类型 | 科普冷知识、生活小妙招、学习小技巧、健康小贴士、河南理工校史趣闻、节气/节日知识，随机混搭 |
| 产出数量 | 每天 1-2 条，每条出 2-3 个候选版本（文案 + 配图） |
| 文案长度 | 150-250 字 |
| 文案风格 | 阳光正能量、有趣有用、不枯燥；先讲知识点，再给一句话总结或启发 |
| 文案口吻 | 第一人称"小青"，如「哈喽小栗子们，小青来分享一个超实用的生活小技巧啦！」 |
| 必须标签 | `#每日话题#`，可加 `#小青爱分享#` / `#冷知识#` / `#生活小妙招#` 等 |
| 配图类型 | 写实风格：科普→科技/自然摄影；生活→居家场景；学习→书桌/笔记；校史→老照片风 |
| 配图比例 | 竖屏或正方形，灵活 |
| 配图水印 | 角落印「小青爱分享」+ 日期，白色半透明 |

## 三、交互功能规范

### 3.1 生成按钮（顶栏区域）

| 按钮 | 功能 |
|------|------|
| 🎯 一键生成全部 | 同时生成天气 + 推荐 + 分享三个模块的全部候选内容 |
| 🌤️ 生成天气 | 只生成早晚安理工模块 |
| 📚 生成推荐 | 只生成小青超推荐模块 |
| 💡 生成分享 | 只生成小青爱分享模块 |

### 3.2 单条内容操作按钮（每条候选右下角）

| 按钮 | 功能 |
|------|------|
| 📋 复制文案 | 一键把（正文文案 + 标签）复制到系统剪贴板，弹窗提示"文案已复制" |
| 💾 保存图片 | 把这张图片存到「小青素材/当天日期/」文件夹，同时标记此条为「已精选」 |
| 🔄 换一条 | **只重新生成这一条**的文案 + 配图，其他候选不改动 |

### 3.3 模块级操作按钮（每个模块标题旁）

| 按钮 | 功能 |
|------|------|
| 🔄 全部重来 | 清空这个模块的所有候选，重新生成全新一批 |

### 3.4 打包功能（底栏区域）

| 按钮 | 功能 |
|------|------|
| 📦 打包精选内容 | 把当天**标记过"已精选"**（点过保存图片或复制文案）的所有文案 + 图片打成 zip，存到当天日期文件夹，弹窗提示路径 |
| 🗂️ 打包全部草稿 | 把当天**生成过的所有内容**（包括没挑中的废稿）全部打成 zip，方便回头翻找灵感 |

## 四、文件存储规范

### 4.1 根目录位置
- 默认：软件 exe 所在目录下的 `小青素材/` 文件夹
- 可在设置页修改存储路径

### 4.2 目录结构
```
小青素材/
└── 2026-08-29/              # 按日期分文件夹（YYYY-MM-DD）
    ├── 天气_早安/
    │   ├── 文案1.txt
    │   ├── 配图1.jpg
    │   ├── 文案2.txt
    │   └── 配图2.jpg
    ├── 天气_晚安/
    ├── 推荐_书籍/
    ├── 推荐_电影/
    ├── 推荐_纪录片/
    ├── 分享_科普/
    ├── 分享_生活/
    ├── 全部备份.json       # 当天所有生成内容的结构化备份（含文案、图片路径、标签、是否精选）
    ├── 精选内容_2026-08-29.zip
    └── 全部草稿_2026-08-29.zip
```

### 4.3 命名规范
- 文案文件：`文案N.txt`（N=1,2,3...）
- 配图文件：`配图N.jpg`（JPG 格式，压缩质量 85%）
- 打包文件：`精选内容_YYYY-MM-DD.zip` / `全部草稿_YYYY-MM-DD.zip`

## 五、设置页面规范

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| Agnes AI API KEY | 文案和配图生成用 | 用户提供（预填） |
| Agnes AI 画图模型 | 固定为 agnes-image-2.1-flash，可修改 | agnes-image-2.1-flash |
| 和风天气 API KEY | 天气查询用 | 用户提供（预填） |
| 素材存储路径 | 小青素材文件夹位置 | 软件目录/小青素材 |
| 必须标签 | 四个必须标签，可增删修改 | #早安理工# #晚安理工# #小青超推荐# #每日话题# |
| 图片保存质量 | JPG 压缩质量 1-100 | 85 |

## 六、异常处理要求

1. **网络不通 / API 超时**：弹窗提示「网络连接失败，请检查网络后重试」，不崩溃
2. **API KEY 无效 / 额度用完**：弹窗提示「XX 服务调用失败，请检查 API KEY 或额度」，附跳转设置页按钮
3. **画图失败**：文案照常显示，图片位置显示「图片生成失败，点「换一条」重试」占位图
4. **存储路径不可写**：弹窗提示「存储路径无法写入，请在设置页更换路径」

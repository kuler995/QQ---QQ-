# 03 - UI 设计规范

> 本文档定义淡蓝色主题的视觉规范：色值、字体、间距、布局、组件样式。
> 所有界面设计必须严格遵守，保证整体风格统一清爽。

---

## 一、主题色板（淡蓝色系）

| 用途 | 色值（HEX） | 说明 |
|------|-------------|------|
| 主色（Primary） | `#4A90D9` | 标准淡蓝，按钮主色、强调色 |
| 主色悬停 | `#3A7BC8` | 鼠标悬浮时的深色版本 |
| 主色按下 | `#2E6AB0` | 点击按下时更深 |
| 背景主色（Bg） | `#EBF4FB` | 整体窗口背景色，非常浅的蓝 |
| 卡片背景 | `#FFFFFF` | 内容卡片白底 |
| 卡片边框 | `#D4E6F7` | 淡蓝描边 |
| 次级背景 | `#F4F9FD` | 模块面板背景，比主背景略深一点 |
| 主文字色 | `#2C3E50` | 深灰蓝，正文文案 |
| 次级文字 | `#7F8C8D` | 灰蓝，辅助说明、时间戳 |
| 成功色 | `#27AE60` | 保存成功、复制成功提示 |
| 警告色 | `#F39C12` | 警告提示（如额度不足） |
| 错误色 | `#E74C3C` | 错误弹窗、失败提示 |
| 分割线 | `#E1EFFA` | 模块之间、卡片之间的分割线 |

## 六、按钮样式规范

### 6.1 主按钮（蓝色实心）
```
背景：#4A90D9 → 悬停 #3A7BC8 → 按下 #2E6AB0
文字：白色 13px 中等
边框：无
圆角：6px
阴影：轻微下阴影（0 2px 4px rgba(74,144,217,0.2)）
例：🎯 一键生成全部、📋 复制文案
```

### 6.2 次按钮（蓝色描边）
```
背景：#FFFFFF → 悬停 #EBF4FB
文字：#4A90D9 13px 中等
边框：1px solid #4A90D9
圆角：6px
例：🔄 换一条、💾 保存图片
```

### 6.3 普通按钮（灰色描边）
```
背景：#FFFFFF → 悬停 #F4F9FD
文字：#2C3E50 13px 常规
边框：1px solid #D4E6F7
圆角：6px
例：⚙️ 设置、📜 历史
```

### 6.4 警告按钮（红色描边）
```
背景：#FFFFFF → 悬停 #FDEDEC
文字：#E74C3C 13px 常规
边框：1px solid #E74C3C
圆角：6px
例：🗑️ 清空、❌ 取消
```

## 八、提示弹窗规范

所有提示用 QMessageBox 自定义样式（淡蓝色主题），不用系统原生框：

| 类型 | 图标 | 按钮 |
|------|------|------|
| ✅ 成功 | 绿色对勾 | [知道了] |
| ⚠️ 警告 | 黄色感叹号 | [确定] / [取消] |
| ❌ 错误 | 红色叉号 | [重试] / [去设置] / [知道了] |
| ℹ️ 信息 | 蓝色 i 字 | [知道了] |

## 九、加载状态规范

- **生成中**：按钮置灰不可点，旁边显示 `⏳ 生成中...` 动画（旋转圆圈）
- **单条卡片换一条**：该卡片显示半透明蒙层 + 小旋转圆圈，其他卡片正常操作
- **全部重来**：整个模块面板显示加载蒙层
- **进度提示**：底栏状态区实时显示「正在生成文案... 2/5 完成」「正在画图... 3/6 张」

## 十、水印叠加规范（图片处理）

| 项目 | 规范 |
|------|------|
| 位置 | 右下角，距离边缘 16px |
| 内容 | 例：「早安理工 · 2026-08-29」 / 「小青超推荐」 |
| 字体 | 微软雅黑，加粗 |
| 字号 | 根据图片宽度自适应：图宽 < 600px 用 18px，600-1200px 用 24px，>1200px 用 32px |
| 颜色 | 白色 `#FFFFFF` |
| 透明度 | 80% 不透明（Alpha=204） |
| 描边 | 1px 黑色半透明描边，保证在亮图上也能看清 |
| 禁止遮挡 | 水印最多占图片底部 10% 高度，绝不压画面主体 |

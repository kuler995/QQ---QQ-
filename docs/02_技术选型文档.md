# 02 - 技术选型文档

> 本文档确定项目技术栈、依赖库、代码架构、配置管理方式。
> 所有技术选型必须在此文档中登记，不得随意引入新依赖。

---

## 一、整体技术栈

| 层面 | 技术选型 | 版本要求 | 选型理由 |
|------|----------|----------|----------|
| 开发语言 | Python | 3.10+ | 生态丰富，AI/API 调用方便，打包成熟 |
| GUI 框架 | PySide6（Qt for Python） | 6.5+ | LGPL 协议可商用，组件丰富，淡蓝色 QSS 主题好做 |
| HTTP 请求 | requests | 2.31+ | 调用和风天气、Agnes AI API |
| 图片处理 | Pillow | 10.0+ | 加水印、转 JPG、压缩质量 |
| 配置管理 | json 配置文件 | - | 简单，不用额外依赖，小白也能手动改 |
| 打包工具 | PyInstaller | 6.0+ | 打包成绿色免安装版，兼容好 |
| 日志 | logging（标准库） | - | 记录运行日志，出问题好排查 |

## 四、配置管理规范

### 4.1 config.json 格式
```json
{
  "agnes_ai": {
    "api_key": "sk-xxxxxx",
    "base_url": "https://agnes-ai.com/api/v1",
    "image_model": "agnes-image-2.1-flash",
    "text_model": "agnes-text-latest"
  },
  "weather": {
    "api_key": "f3967f30ced34e54a417acc145065d67",
    "city": "焦作",
    "location_id": "101181101"
  },
  "storage": {
    "base_path": "",
    "image_quality": 85
  },
  "tags": {
    "required": ["#早安理工#", "#晚安理工#", "#小青超推荐#", "#每日话题#"],
    "morning_extra": [],
    "night_extra": [],
    "recommend_extra": ["#小青爱分享#"]
  },
  "generation": {
    "candidates_per_item": 3,
    "recommend_daily_min": 1,
    "recommend_daily_max": 2,
    "share_daily_min": 1,
    "share_daily_max": 2
  }
}
```

### 4.2 配置读写规则
- 配置文件位置：`src/config.json`（开发时）→ 打包后与 exe 同目录
- **config.json 必须加入 .gitignore**，禁止提交真实 API KEY
- `config.example.json` 保留模板结构，KEY 留空，可以提交
- 首次启动检测不到 config.json 时，从 config.example.json 复制一份，并弹窗引导去设置页填 KEY

## 五、代码规范

### 5.1 编码规范
- 统一 UTF-8 编码，所有源文件头部加 `# -*- coding: utf-8 -*-`
- 函数和类用**中文 docstring** 说明用途、入参、返回值（小白项目，中文易懂）
- 所有网络请求、文件操作必须加 `try-except`，捕获异常后：
  - 写日志（logging.error）
  - 弹友好提示给用户（不显示堆栈）

### 5.2 Prompt 规范
- 所有 Agnes AI 的 Prompt 集中写在 `core/content_generator.py` 顶部常量区
- Prompt 必须明确：角色设定、输出长度、语气风格、标签要求、JSON 格式要求
- 文案生成要求返回 JSON 数组，方便解析多条候选：
  ```json
  [
    {"text": "正文内容（不含标签）", "tags": ["#标签1#", "#标签2#"]},
    {"text": "正文内容", "tags": ["#标签1#"]}
  ]
  ```
- 图片生成 Prompt 必须包含：风格（写实摄影风）、色调、主体内容、画面比例（竖屏/正方形）、禁止水印文字（由我们软件后期叠加）

### 5.3 线程规范
- **所有 API 调用、图片生成、文件打包必须在子线程执行**，禁止阻塞 UI 主线程
- 使用 PySide6 的 `QThread` + 信号槽机制更新 UI
- 子线程禁止直接操作 UI 控件，必须通过信号发消息到主线程更新

## 六、打包规范（PyInstaller）

### 6.1 打包命令（Windows）
```bash
pyinstaller --noconfirm --windowed --name "自动早晚安小助手" \
  --add-data "src/ui/styles;ui/styles" \
  --add-data "src/config.example.json;." \
  --collect-all PySide6 \
  src/main.py
```

### 6.2 打包后目录
```
dist/自动早晚安小助手/
├── 自动早晚安小助手.exe
├── config.example.json
├── PySide6/         （Qt 运行库）
├── ...其他依赖...
└── 小青素材/        （首次运行自动创建）
```

### 6.3 交付方式
- 把 `dist/自动早晚安小助手/` 整个文件夹压缩成 `自动早晚安小助手_v1.0_绿色版.zip`
- 用户解压即可，双击 exe 运行
